# 用户体验内容评估

评估日期：2026-10-03。

## 目标用户与场景

知衡面向有一定投资基础、但不一定熟悉指标公式的普通投资者。主要场景是收盘后或周末完成一次选股研究：表达方向、核对条件、查看结果原因，必要时保存并持续跟踪。

这类用户通常先扫描日期、条件数、结果状态和异常提示，再按需查看公式与来源。因此主路径应短，关键风险应就地出现，操作说明和专业细节应按需展开。

## 评估标准

- 任务相关：信息是否直接支持当前动作或决策。
- 避免重复：同一规则不在相邻区域反复陈述。
- 风险可见：数据日期、缺失值、结果过期和投资边界不能被隐藏。
- 渐进披露：术语、公式、来源和帮助只在用户主动查看时展开。
- 来源可靠：不添加未经确认的客服、邮箱或个人联系方式。
- 跨设备可读：移动端不因说明内容增加页面级横向滚动。

## 已补充的关键信息

- 快速开始：描述或添加条件、筛选、查看原因及后续操作。
- 结果状态：入选、排除、待核实和只差一条的准确含义。
- 操作差异：保存、分享和导出的内容范围、保留方式及隐私边界。
- 常见问题：智能生成不可用、缺失值、零结果和条件修改后的旧结果。
- 数据规则：股票范围、AND组合、财报与行情口径、历史变化及投资边界。
- 帮助资源：公开使用说明、GitHub问题反馈入口和扶摇数据文档。
- 状态降级：智能生成未配置时明确提示仍可手动添加条件。

以上内容统一放入“帮助与说明”弹窗，不占用普通用户的默认操作路径。

## 保留内容及理由

- 行情日期和休市状态：决定结果时效。
- 数据完成数、异常数和数据版本：发生异常时用于复核。
- 条件修改后的旧结果提示：防止把旧名单误认为新条件结果。
- “—”的含义与结果分类：防止把缺失值误读为0。
- 30天及浏览器会话边界：影响保存结果能否找回。
- 不构成买卖建议：属于必要的使用边界。

## 未添加
