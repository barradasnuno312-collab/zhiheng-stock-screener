# 指标与数据字典

规则版本 `zh-v1.1.0`。金额原始单位为人民币元，百分数以百分比数值存储（10表示10%），增速变化单位为百分点。

| 指标 | 来源字段/窗口 | 计算与限制 |
| --- | --- | --- |
| 营业收入同比 | `operating_income` | （最新已披露累计报告值÷上年同报告期−1）×100；基期须为正 |
| 营收同比增速变化 | 同字段，当前/上一连续报告期及各自上年同期 | 当前累计同比减上一累计同比；不是单季环比 |
| 归母净利润同比 | `parent_holder_net_profit` | 同期同比，不能以普通净利润替代；基期非正不算普通同比 |
| PE(TTM) | `pe_ttm` | 直接取供应商值；非正值标记不适用 |
| PB(MRQ) | `pb_mrq` | 直接取供应商值；非正值标记不适用 |
| 近60日年化波动率 | `close_price`，`adjust=forward`，61个连续交易日 | 60个简单日收益率，样本标准差×√252×100 |
| 近60日最大回撤 | 60个连续交易日的前复权收盘价 | 窗口内峰值至后续谷值最大跌幅，按正数百分比显示 |
| 近20日日均成交额 | `turnover`，20个连续交易日 | 算术平均；缺失、零成交/停牌或缺日时不形成正常窗口 |
| 近20日收益率 | 21个连续交易日的前复权收盘价 | 最新收盘价÷20个交易日前收盘价−1；历史收益不代表未来表现 |
| 收盘价相对20日均线 | 20个连续交易日的前复权收盘价 | 最新收盘价÷20日收盘价算术平均−1 |

旧不可变快照不覆盖写入。新增的两个价格指标可从旧快照中已经通过连续性核验的61个收盘价输入即时复算；若旧快照没有这组有效输入，则保持待核实，不以不完整日线补算。

财报元字段为 `period_end_ms`（报告期末）、`report_date_ms`（披露时点）、`currency`（币种）。只取不晚于刷新研究时点的已披露报告；同报告期取当时已知最新披露版本。上年同期与本期币种须均为CNY。

真实报表累计口径尚未验证前，`FUYAO_CUMULATIVE_VERIFIED` 必须为false，财务同比显示待核实。接口文档示例不能替代真实抽查。

## 接口

- 交易日历：`/api/a-share/calendar/trading-days`
- 沪深300成分：`/api/a-share-index/constituents/ths-stock-list?thscode=000300.SH`
- 估值快照：`/api/a-share/valuations/snapshot`，每批100只
- 前复权日线：`/api/a-share/prices/historical`，逐股
- 利润表：`/api/a-share/financials/income-statements`，`period=quarterly&limit=12`，逐股

HTTP状态与业务 `code` 同时校验。6秒请求超时、最多2次退避重试（1秒/2秒）、数据库锁保证请求启动间隔至少550ms。不可重试的权限/业务错误不继续整池请求；成员保留未知原因。

## 时间语义

自然日一律按Asia/Shanghai。收盘前排除当天；休市日沿用最近已完成交易日。

`fetchedAt`是请求/快照抓取时间，不是报价或披露时间。`sourceTimestamp`取自供应商响应元信息；估值接口只提供响应中最大有效时间，`timestampScope=response_max_only`，不推断每股同步更新。响应时间早于目标行情日时提醒可能过时。

逐指标证据保留：原始字段和值、归一化值、单位、报告期、披露日、行情日、抓取时间、时间粒度、来源接口、请求ID、公式版本及状态。上游没有提供的时点保留null／“未提供”。

## 分类

每条条件：可用值满足则pass，不满足则fail；缺失、不适用、错误则unknown。

AND汇总：有fail则排除；无fail但有unknown则待核实；全部pass才入选。排除股票仍保留其他缺失证据。“只差一条”要求恰好一项fail且其他全部pass。

比较严格区分条件变化与数据变化。条件比较必须同一快照；监控使用新快照时分别呈现明确移出、变为待核实、加入或离开股票池。

历史快照复盘最多读取系统真实保留的7个快照，以固定策略条件逐份重算三态结果并显示名单变化。它不补造历史指数成员、不计算持有期收益，也不称为收益回测。

## 缓存及授权

必要事实与计算证据只存于私有应用数据库，不进入公开源码。最新7份快照和仍被结果引用的旧快照予以保留。应用通过匿名访客会话隔离保存记录，不提供整库下载或开放数据转售接口。
