# 120秒演示脚本

使用已发布页面和真实快照录制；录屏从访问验证完成后开始，避免展示访问码。下列股票、数量与日期均以当次界面为准。

| 时间 | 操作 | 讲述要点 |
| --- | --- | --- |
| 0—15秒 | 展示工作台与数据状态 | “知衡把选股想法变成可以核查、修改和持续跟踪的条件。范围是完整沪深300，行情日期与取数覆盖明确显示。” |
| 15—40秒 | 点击“经营改善”，生成条件 | “AI负责理解意图。改善、估值不贵、历史稳定都需要具体代理指标，阈值由使用者确认。”按需展开“了解这个指标”，核对通俗含义与计算口径。 |
| 40—60秒 | 点击“筛选 N 条条件”；打开一只股票 | “筛选按钮同时完成确认和执行，每个判断来自确定性计算。”先看判断原因，再展开营收同比的原始数据、报告期、披露日和公式。 |
| 60—75秒 | 切换排除／只差一条 | 展示一条实际未满足的条件。如果存在待核实，说明缺值不会被当成0；没有该状态时不伪造样例。 |
| 75—95秒 | 修改一项阈值，重新筛选，打开结果变化 | “这里固定同一份数据，所以名单变化可以归因于条件修改。”读出界面实际新增、移出和保留数量。 |
| 95—110秒 | 保存本次筛选，进入策略与跟踪，开启并立即更新 | 展示固定版本与实际检查记录；休市时如实展示无新交易日，不能讲成已产生收益。 |
| 110—120秒 | 打开已保存版本 | “AI解释意图，程序计算，数据提供证据。这里不预测涨跌，也不做买卖建议。” |

## 操作备选

AI请求失败或额度不足时，展示明确提示并使用手动条件编辑；不能用预录文本冒充实时模型。若初始条件没有入选，保留零结果，使用“只差一条”分析后调整阈值。

需要更短演示时使用“成长与估值”：PE小于30倍、营收同比大于10%。随后将PE上限改为10倍，其余条件不变。实际变化仍以当前快照计算结果为准。

## 录制前核对

确认行情日期、300成员覆盖、访问码会话、解析额度和至少一个可恢复策略。检查麦克风、屏幕大小和录屏范围；不录入供应商后台、账户凭证或其他工作区资料。

此文件是操作与讲述脚本，不表示已经录制视频，也不表示完成了真实用户可用性测试。
