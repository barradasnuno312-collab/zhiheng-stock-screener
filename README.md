# 知衡 · 自然语言选股与策略解释器

把“我想找什么股票”，变成“我能核查、调整和持续跟踪的一组条件”。

知衡面向有投资基础的普通投资者，将中文研究想法转成可编辑条件，在完整沪深300股票池上以真实数据逐项核验。AI负责理解意图；金融计算、分类、比较与监控由确定性程序执行。

**[在线体验](https://bytedance.feishuapp.cn/app/app_17f88a68s0k)**：需要作品访问码，无需飞书企业账号。**[公开源码](https://github.com/barradasnuno312-collab/zhiheng-stock-screener)**可匿名访问；维护者可通过[妙搭管理入口](https://miaoda.feishu.cn/app/app_17f88a68s0k)继续开发。

2026-10-02已取得真实完整300成员快照，行情日为2026-09-30，取数异常0只；36项算法/回归测试、13组真实模型表达、37项线上流程检查通过。桌面Chrome已完成从解析到保存、跟踪和恢复的主流程；移动端使用结果卡片，不依赖横向表格完成核查。零取数异常不表示所有指标适用，负估值、缺值与不可比财务值仍有明确状态。每日调度、浏览器和最终发布状态详见[验证记录](docs/test-report.md)。

## 体验流程

1. 输入评审访问码，建立独立访客会话。
2. 输入“经营改善、估值不要太贵、走势相对稳定”，查看代理指标、阈值建议与澄清。
3. 编辑条件，点击“筛选 N 条条件”完成确认并执行，查看入选／排除／待核实。
4. 点击股票先看判断原因；按需展开指标含义、计算方式、原始输入、来源与时点。
5. 修改一个阈值，用同一快照比较名单变化。
6. 导出当前结果或复制条件分享链接；保存不可变策略版本。
7. 恢复当时结果，跨真实保留快照复盘，为固定版本开启条件监控。

财务、估值、波动率、回撤、成交额、20日收益和均线距离共10项指标。组合为AND；OR、行业百分位、预测和直接买卖请求明确列为未支持。无符合结果时解释约束，不预设股票名单。

## 本地开发

本项目依赖**妙搭全栈运行时、平台数据库、官方AI插件和扶摇数据API**。公开源码不是无需平台账号即可离线运行的独立金融数据服务。

环境：Node.js ≥22、npm ≥10、已授权的 `lark-cli`，以及自己的妙搭应用与扶摇访问权限。仅使用已有或免费额度，不自动购买服务。

```bash
# 在自己拥有的妙搭full_stack应用中初始化本地模板
lark-cli apps +init --app-id <your_app_id> --dir ./zhiheng
# 将本作品业务源码合入模板，保留自己应用的私有配置
npm install
lark-cli apps +plugin-install --help
# 按CLI当前说明安装 @official-plugins/ai-text-to-json@1.0.26
lark-cli apps +env-pull --app-id <your_app_id> --as user
```

将 `server/database/migrations/` 中的业务DDL在自己的**dev**环境执行，随后 `npm run gen:db-schema`。应用数据库连接由平台配置，不自行建立第二套数据库连接。服务端变量见 [.env.example](.env.example)，真实值仅写私有环境文件或平台环境变量。

```bash
npm run dev
npm run type:check
npm test
npm run build:prod
```

`npm run dev` 会同步平台依赖与技能并拉取开发配置。不要同时运行生产构建和真实接口验收：两者共用模板的编译目录，构建会使watch服务短暂重启。

## 自动化与发布

在自己应用中配置并绑定3个自动化触发器（名称与代码一致）：

| 名称 | 条件 | 用途 |
| --- | --- | --- |
| `zhResearchJob` | `zh_jobs` INSERT | 处理解析、取数分片、监控任务 |
| `zhDailyMonitor` | `30 16 * * *`，Asia/Shanghai | 按交易日历刷新并检查启用策略 |
| `zhRecovery` | `*/30 * * * *`，Asia/Shanghai | 恢复中断或遗漏任务 |

开发态可使用需要独立管理凭证的逐任务执行接口；它在生产环境返回404。这个入口不替代云端定时验收。

提交业务代码至应用 `sprint/default`，推送后通过 `lark-cli apps +release-create` 发布，等待 `+release-get` 返回 `finished`。评审入口需平台允许公开访问，同时业务API由服务端访问码会话守卫保护。访问码与管理凭证必须不同。

## 数据与边界

- 扶摇是首版核心事实来源；供应商API Key只在后端使用。
- 仅完成交易日的价格窗口；财报按披露时间过滤；字段缺失不当成0。
- 负PE、基期非正值、不可比或未验证口径单列不适用/待核实。
- 300只成员保留明确状态；任何明确fail则排除，没有fail但有unknown则待核实。
- 快照与保存版本不可变；改条件时固定数据版本；监控中的缺失与明确移出分开。
- 估值响应最大时间不是每只股票的更新时间；抓取时间不冒充行情日或披露日。
- 历史快照复盘只复算系统真实保留的数据版本，不补造历史成分、不计算收益回测；不做收益承诺、买卖建议或自动交易。

测试中只有明确标注的合成样例，不在产品中展示，不包含真实金融缓存、账号信息或个人材料。
